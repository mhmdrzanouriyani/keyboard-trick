## ⚠️ Disclaimer

> This project is for **educational purposes only**.
> It demonstrates keyboard input monitoring techniques for learning Python's `pynput` library.
> **Never use this on a machine without the owner's explicit consent.**
> Unauthorized monitoring of keyboard input is illegal in most countries.

---

## ✨ What It Demonstrates

- How to use `pynput` to listen to keyboard events
- How to handle special keys (Space, Enter, Backspace, ESC)
- How to write buffered input to a log file
- How to gracefully stop a listener

---

## 🚀 Quick Start

### 1. Install dependency
```bash
pip install pynput
```

### 2. Run
```bash
python "control keyboard/keyboard.py"
```

### 3. Stop
Press **ESC** to stop the listener and save remaining keys.
